# MEIN TAL 1919

Maison Suzanna Bars — https://meintal1919.ru/

Responsive static landing page for the 24 March 2027 fashion show. The desktop design follows the approved ivory invitation rail. Mobile preserves the original Suzanna portrait and turns the rail into a compact information block.

## Edit

- `index.html`: content and semantic elements with stable IDs for onUI annotations.
- `styles.css`: desktop and mobile layout, spacing and typography.
- `app.js`: accessible mobile navigation and temporary information dialogs.
- `assets/`: local image and font assets. Portrait is derived from the supplied original photograph, with an alpha cutout and global colour adjustment; no generated changes to face, body, clothing or pose.

Run locally with `python3 -m http.server 4173` and open http://localhost:4173.

GitHub Pages publishes the `main` branch root. The custom domain is configured as `meintal1919.ru`.

Ticket and accreditation URLs have not yet been supplied. At the owner's request their buttons currently show “Информация скоро появится.” Update the links when ready. onUI can annotate normal page elements without code instrumentation.
